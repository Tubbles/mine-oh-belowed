## The ground's colours (0307)

Tags: generation, climate, look, shader, field, mesa, 0307, 0317, 0320, 0321, 0322

The climate's seed took purpose 26, since 0306 had taken the prototype's 25, so the default home is 13.3 °C and 88 percent moisture at 8 km rather than the design's 12.6 and 70, still lush green. The review found faint grass on a mined floor where the topsoil meets the stone: only topsoil vertices of a grid holding loaded samples measured their cut, a stone vertex counted natural, and the edge between them interpolated grass. Every vertex of such a grid now measures, which brings the meshing of a grid holding loaded samples to about 1.9 times its cost before 0307 at the home and 2.4 times in the wild (debug build, measured on a loaded machine). Grids generated whole are unchanged. The field renderer took the chunk renderer's fallback for an old overlay copy and checks for the atlas sampler, since a field.fs from before 0307 links with the new field.vs. The reverse pair, an old field.vs with the new field.fs, also links on desktop Mesa and draws without the looks, while GLSL ES refuses it. The main agent's capture found that the new field.vs named a parameter `packed`, a reserved word that glslangValidator passed and Mesa refused: the field drew nothing and the developer command `tick` waited forever, and the first capture of this item had been blamed on the machine's load for an hour before the log was read. The second fix round renamed it, added a test of the reserved words of GLSL 3.30 and ES 3.00, and compiled every shipped pair through Mesa's surfaceless EGL, which becomes the checks' tool in 0320. The silent session without a renderer is 0317. The captures also show 0306's relief cracking between detail levels along far crests (0321), and the small ledges kept from before 0306 striping every slope with rock bands now that steep faces take the rock look (0322). Gladio on the phone has not run the new shader. The next phone playtest checks it.

## The toolchains float (0315)

Tags: build, ci, toolchain, odin, android, sdl3, nix, 0315, 0319

CI's `nix` job had failed on every push since 2026-11-05, unnoticed because no landing looked at CI: `flake.nix` follows `nixos-unstable` without a lock, nixpkgs moved Odin from dev-2026-09 to dev-2026-10, and dev-2026-10 refuses every `odin check -target:windows_amd64` on a Linux host without `-windows-sdk-root`, a flag only its `build` takes. The build and every test passed there. Offered a pin, the user chose the opposite: "Have packages float on latest as a general rule, and we'll integrate them as necessary as it shows up", and approved moving the local Odin. The Windows check left the flake rather than being patched for one release, since the `windows` job compiles and links that target natively on every push (dev-2026-11 refuses only commands that link, so `./build.sh check-windows` runs again locally). The code compiles for the desktop on dev-2026-09, 10 and 11a, since nixpkgs lags the releases, but for Android only on 11a: its runtime uses ELF thread local storage, which Android loads from level 29, so the minimum moved from 28 and Android 9 phones lose the APK (the user, on Android 17: "absolutely"). Two Android changes in 11a no check reported, both found by building the library with each compiler: the library now starts its runtime from an INIT entry, so `__wrap_main` would start it a second time into 0116's assert, and `ANativeActivity_onCreate` is no longer exported unless the link keeps it. 11a's bundler also runs `zipalign -P 16`, which build-tools 34 lacks, so the couch's SDK took build-tools 37 and NDK 30 at the user's word. The review found `os.args` on Android now built from `/proc/self/cmdline` before raylib's argv arrives, empty if the file cannot be read, so the arguments' slice is guarded, and NDK release candidates passing the installer's stable filter. What stays pinned says why beside the pin: raylib 6.0 (patched, committed archives, 0319 moves it to 6.2), the target SDK 34, the command line tools zip that bootstraps `sdkmanager`, and the Fedora toolbox image the container is made from once.
