- Toolchain: Odin dev-2026-09 (nightly a2fb372) at `~/opt/odin-linux-amd64-nightly+2026-09-01`, symlink `~/opt/odin`. raylib 6.0 comes bundled as `vendor:raylib`.
- Linking on Bazzite: the image has runtime X11 libraries but no development symlinks. A shim directory with `libX11.so -> /usr/lib64/libX11.so.6` passed through `-extra-linker-flags:-L` makes raylib link. Verified with a hello world. Not run: this session was headless.
- Controller path: the Steam Input API needs a Steam app id the account owns, so a non-Steam shortcut only gets an emulated XInput pad plus keyboard and mouse. Trackpad position, grip buttons and raw gyro are reached by reading the controller directly through SDL3's HIDAPI driver (`SDL_hidapi_steam_triton.c`, present in the host SDL 3.4.16), with Steam Input disabled for the shortcut. Fallback if the spike fails: the Steam Input translation layer through raylib. Final call after work item 0002.
- Odin standard library coverage checked: `core:encoding/json` parses SJSON, `core:math/noise` has OpenSimplex2, `core:compress/zlib` only inflates. The save format therefore uses palette plus run length encoding instead of zlib.
- Nix flake written but not verified locally (nix is not installed on this machine). CI is the check.
- Steam library shortcut deferred (work item 0003) until a binary exists. The Steam client was not running during the session, and `shortcuts.vdf` must be edited while Steam is closed anyway.
