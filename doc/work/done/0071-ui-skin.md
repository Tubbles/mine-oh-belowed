# 0071 UI skin and map visuals

Status: implemented
Milestone: M11

## Goal

Panels are flat rectangles with a default font. A consistent 10 foot theme: fonts, an icon set, panel art, and a map with shaded terrain.

## Deliverables

- A font pair (heading and body) with clear glyphs at 10 feet, an icon set for actions and categories, panel frames and dividers, focus and hover states, all data files under `data/ui`.
- The map screen shades terrain by height and biome and draws machines as icons.
- Tests: the audit passes with the new metrics.

## Verify

- Builds and tests pass.
- User: Screenshots of every screen.

## Notes

Scope decisions (main agent, 2026-09-28): the font pair came with 0077 (Exo 2 for headings in bold and body, a monospace family for diagnostics, chosen on the Display tab), and the map's height and biome shading came with 0038 and 0058; both are done. Machines as icons on the map are dropped: at one block per pixel a three block machine is three pixels, so the map keeps dots and colours them by machine category instead. This item delivers the theme file, panel art, focus and hover states, and the icon set.

Implementation pointers, decisions taken so the item is unambiguous:

- Theme from data: `data/ui/theme.sjson` holds the colours (`panel`, `panel_edge`, `panel_highlight`, `widget`, `widget_hover`, `widget_active`, `accent`, `text`, `text_dim`, `focus`, `divider`, `tooltip`, `toast`, `danger`, `map_marker_*` by category), the metrics (`row_height`, `slot_size`, `padding`, `gap`, `border`, `corner`, the text sizes) and the font roles (`heading`, `body`, `monospace`, ids from `data/fonts/fonts.sjson`, the Display tab's font choices override the roles), loaded into a `Ui_Theme` (new `src/ui_theme.odin`) in `Ui_State`, validated with defaults for missing keys equal to today's constants, hot reloaded as presentation data (a `Theme` category in `src/data_watch.odin` and `src/hot_reload.odin`). The constants in `src/ui_widgets.odin` (`UI_PANEL_COLOR`, `UI_ROW_HEIGHT` and the rest) become reads of the theme; the layout code keeps its names through short accessors so the diff stays readable. The UI audit runs with the shipped theme.
- Panel art with primitives, no images: a panel is a fill, an outer edge line and an inner highlight line one border inside, corners cut by `corner` (an octagon from two fills, so no rounded rectangle code), dividers as one border thick lines in `divider`; buttons and slots get hover (`widget_hover`) and active (`widget_active` while Confirm is held) states from `widget_background`, the focus outline stays the accent and pulses gently (a sine of the frame time, the amplitude a theme value) so the focused control is found at ten feet; tabs get an accent underline on the selected tab; sliders a filled track; toggles a knob that slides. Tooltips get the edge line too.
- Icon set: `data/ui/icons/<name>.png`, 16 by 16 RGBA, generated by `tools/make_placeholder_textures.py` under a new `ui` family (gamepad buttons `button_south`, `button_east`, `button_west`, `button_north`, `bumper_left`, `bumper_right`, `trigger_left`, `trigger_right`, `stick_left`, `stick_right`, `dpad`, `menu`, `view`, the keyboard fallback `key` (a blank key cap the label is drawn on), the item categories `category_raw`, `category_intermediate`, `category_tool`, `category_machine`, `category_block`, and `mission_control`, `journal`, `map`, `settings`, `search`), packed into a UI atlas by the item atlas code (`src/render_icons.odin`, a second `Item_Atlas` over that directory) and drawn through a new `Ui_Icon` draw command (`src/ui_core.odin`, `src/ui_draw.odin`). The glyph bar (`glyph_key` in `src/ui_widgets.odin`) draws the button icon in place of the lettered box on the gamepad, with the letter drawn on the key cap icon for the keyboard; the recipe browser's category tabs and the inventory tabs show their icons before the label.
- Map (`src/ui_map.odin`): entity dots take the category colour of their machine's item from the theme.
- Tests (`src/ui_theme_test.odin`): the theme parses, missing keys take the defaults, a wrong type is refused with the file named, the shipped theme has every key; the UI icon atlas packs every file; the glyph icon per button and device; the UI audit passes at every size with the theme, the icons and the focus pulse at its extremes.
- Docs: `doc/ui.md` (a Theme section: the file, the art rules, the icons), `doc/content.md` (the `data/ui` files), `doc/architecture.md` (hot reload categories), `doc/log/2026-09-28.md`, this item's Status and Notes.
