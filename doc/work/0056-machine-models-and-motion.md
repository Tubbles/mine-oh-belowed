# 0056 Every machine a model, and one moving part each

Status: todo
Milestone: M11

## Goal

With the pipeline in place, every machine gets a model and one part that moves with its state, so a glance tells what a machine does and whether it works.

## Deliverables

- Models for every machine kind in `data/models` (placeholder quality generated by script, replaced by hand later): drills, inserters, belts (scrolling texture), splitters, lifts and ramps, furnaces, alloy furnace, crusher, washer, assemblers, labs, chests, pumps, boilers, engines, poles and substations, tanks, pipes, refinery, cracking unit, chemical plant, gasifier, electrolyser, generators, flare stack, hydro turbine, recycler, bore drill, core sample drill, seismic thumper, launch pad, capsule.
- One animation per kind driven by entity state at render time (no simulation change): drill arm pumping, inserter arm swinging with its item, furnace and boiler glow, assembler wheel, pump piston, engine flywheel, lab lights, refinery flare, electrolyser bubbles, rocket standing on the pad and lifting on launch. Emissive parts show working versus idle.
- The bottleneck overlay markers move to the model tops.
- Tests: state to animation phase mapping as pure procedures, every machine names a model that loads.

## Verify

- Builds and tests pass.
- User: Screenshots of a working line.
